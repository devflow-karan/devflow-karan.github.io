# Karan Kumar — Portfolio

Single-page portfolio site, ready for GitHub Pages.

## Deploy in 5 steps

1. Create a new GitHub repo named `devflow-karan.github.io` (must match your username exactly, so it serves at the root domain — or use any other repo name if you're fine with a `/reponame/` URL instead).
2. Upload `index.html` and `Karan_Kumar_Resume.pdf` to the repo (drag-and-drop on github.com works, or `git push`).
3. Go to **Settings → Pages** in the repo.
4. Under **Build and deployment**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`. Save.
5. Wait 1–2 minutes, then visit `https://devflow-karan.github.io` (or the URL GitHub shows you on the Pages settings screen).

## Editing later

Everything is in `index.html` — one file, no build step. Open it in any editor, change the text, and push again to update the live site.
